Research prototypes that turn book chapters on IoT, edge AI and smart industry into runnable, tested code. Each one checks the book's claims against measurements and reports where they do not hold. All run on simulated data; hardware drivers are included but not yet tested on real devices.

| Project | What it does | 說明 |

| [voice-iot-home](https://github.com/Loggo-MediCare/voice-iot-home) | Keyword-spotting smart light and speaker-verification door (MFCC, DS-CNN, LSTM) | 語音控制智慧燈與語音門禁 |
